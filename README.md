## Now available: Retention messages for subscriptions  

###### November 04, 2026  
<p>Reduce cancellations with retention messages that remind subscribers of your subscription's value as they decide whether to cancel. Retention messages appear in the cancellation flow and can include text, images, or a special offer.</p><p>In App Store Connect, you can configure retention messages for your auto-renewable subscriptions, including subscriber eligibility and the wait time between messages. With the <a href="https://developer.apple.com/documentation/retentionmessaging/">Retention Messaging API</a>, you can choose which message to show each subscriber based on their subscription details. API access is available by request.</p><p><a href="https://developer.apple.com/help/app-store-connect/manage-subscriptions/configure-retention-messages/">Configure retention messages in App Store Connect</a></p><p><a href="https://developer.apple.com/app-store/subscriptions/">Learn about auto-renewable subscriptions</a></p>
